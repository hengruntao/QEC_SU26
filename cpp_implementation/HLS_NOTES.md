## Known C++ and RTL differences

These are deliberate unresolved differences, not HLS conversion mistakes:

- The C++ RNG uses a 32-bit LFSR and advances it three times when a new Relay leg begins.
- The current RTL VNU uses an 8-bit LFSR that advances on each enabled cycle.
- The C++ memory-strength multiplication performs per-bit shift and truncation before summing partial terms.
- The current RTL performs a full multiplication, adds a rounding offset, and then right-shifts.
- The C++ VNU applies a newly generated beta during the same `new_leg` call. RTL nonblocking timing may apply the previous beta during that clock edge.

Do not silently make these implementations match. Resolve each behavior against the paper, Relay reference, and intended hardware architecture, then add a test that fixes the chosen rule.
